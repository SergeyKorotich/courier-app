Курьер — смены
PWA-приложение для водителей-курьеров: запись смен, отрезков маршрута,
перевозок врачей и справочник врачей/клиник. Работает офлайн, данные
синхронизируются с Google Таблицей через Apps Script Web App.

Как это устроено

Телефон (PWA, GitHub Pages)
   │  index.html + app.js + sw.js
   │  localStorage: справочники, открытая смена, офлайн-очередь
   ▼
Apps Script Web App (api.gs)
   │  doGet — выдаёт справочники + последние 500 смен
   │  doPost — принимает пакеты записей (shift/segment/doctor/…)
   ▼
Google Таблица
   Drivers, Shifts, SegmentsAPI, Doctor, DoctorsRef,
   Points, MedPoints, InterPoints, DoctorsRef, SyncLog, Врачи, Клиники
Офлайн-режим. Ввод работает без сети: смена хранится в
localStorage, отправки падают в очередь и уходят автоматически при появлении сети.
Аутентификация. ФИО + PIN по листу Drivers. Роль «старший» открывает кнопку «Статистика всех водителей».
Справочники. Врачи и клиники ведутся на листах «Врачи» и «Клиники», правки с телефона уходят в таблицу.
Файлы
Файл	Назначение

app.js	Вся клиентская логика
sw.js	Service Worker: кэш статики, офлайн-запуск
manifest.json	PWA-манифест

api.gs	Сервер: Apps Script, деплоится отдельно
Деплой
Фронтенд (GitHub Pages). Правки в index.html/app.js/sw.js → commit + push. При изменении статики обязательно поднять версию кэша в sw.js.

Бэкенд (Apps Script). Правки в api.gs → сохранить → «Развернуть → карандаш → Новая версия → Развернуть». URL веб-приложения прописан в app.js.

Разовая настройка. В таблице выполнить apiSetup() — создаст листы с нужными заголовками. На листе Drivers должны быть колонки ФИО и PIN.

Листы таблицы
Drivers — ФИО, автомобиль, госномер, роль, PIN.
Shifts — одна строка на завершённую смену: даты, одометры, пробег, маршрут, заправка, продолжительность, врачи, статус.
SegmentsAPI — отрезки смены (откуда/куда/километраж/тип).
Doctor — перевозки врачей с назначенным и фактическим временем.
Врачи, Клиники — справочники с контактами и ссылками на маршруты.
Points / MedPoints / InterPoints — городские, мед- и междугородние точки для подсказок.
SyncLog — журнал синхронизации.
Конвенции данных
Даты — строка ГГГГ-ММ-ДД; время — чч:мм.
Ключи записей — timestamp-random, генерируются на клиенте.
ФИО — главный ключ водителя: правки авто и переименование ищут строки по нормализованному ФИО.
Планы
Путевые листы: выгрузка PDF по шаблону за день/смену для каждого водителя.
Дашборд руководителя: расширение общего отчёта.
Индивидуальные характеристики пользователей (телефон, доп. поля).
