# Курьер — смены (PWA + Google Apps Script)

Мобильное веб-приложение для водителей: учёт смен и отрезков маршрута, перевозки врачей,
путевые листы (PDF), справочники (врачи, клиники, водители, автомобили) и статистика.
Данные — Google Sheets, серверная логика — Google Apps Script, клиент — одностраничное PWA без сборки.

## Состав файлов

| Файл | Назначение |
|---|---|
| index.html | разметка всех экранов и стили |
| app.js | вся клиентская логика |
| sw.js | service worker: html/js — network-first, остальное — cache-first |
| manifest.json | манифест PWA |
| icon-192.png / icon-512.png | иконки |
| api_1…api_5.txt | код Apps Script (склеиваются по порядку в один файл .gs) |
| appsscript.txt | манифест Apps Script, зона Europe/Samara |

## Архитектура

- **Клиент.** Справочники и смены кэшируются в localStorage (`refCache`, `shiftsCache`).
  Работает офлайн: открытая смена хранится целиком (`appState_v2`), записи уходят через
  очередь (`sendOrQueue` → `flushQueue`, до 3 попыток на пакет). Подсказки полей —
  единый механизм `attachPrefixAc` с фильтром строго по началу названия.
- **Сервер.** `doGet` — данные (`drivers/roles/tariffs/points/.../shifts`), `page=data`
  (отрезки и перевозки по id смен), `page=waybill` (PDF путевых листов, слитый режим,
  email, диагностика). `doPost` — пакетная запись по типам: shift, segment, segmentedit,
  segmentsreplace, shiftupdate, shiftdelete, doctor, doctorsedit, driver, driveredit,
  driverrename, driverprofile, car, caredit, tariffadd, справочники, plnumset.
- **Таблицы:** Shifts, SegmentsAPI, DoctorS, Drivers, Cars, SyncLog, справочники точек
  (Points/MedPoints/InterPoints, DoctorsRef, «Врачи», «Клиники»), Tariffs, шаблон ПЛ.
  Колонки ищутся по нормализованным заголовкам (normHeader/findCol) — порядок не важен.

## Роли

- **водитель** — смены, отрезки, врачи, личная статистика, путевые листы.
- **«старший»** — дополнительно: справочник водителей, назначение ролей, тарифы,
  статистика всех водителей.
- **«бигбос»** — только аналитика: маршруты и перевозки за месяц/неделю/день.

## Путевые листы

Префикс и счётчик — на водителе (лист Drivers, колонки «ПЛ префикс», «ПЛ №»).
Номер выдаётся под LockService, «ранняя дата → меньший номер», фиксируется на смене.
Шаблон — лист PL_SHEET, разрезается по строке медосмотра на лицевую и обратную стороны.

## Деплой и правки

1. Клиент: перезалить app.js / index.html на хостинг (service worker отдаёт их по сети —
   перезагрузка с Ctrl+Shift+R). Номер кэша в sw.js поднимать при правке кэшируемой статики.
2. Сервер: вставить блоки в редактор Apps Script → «Развернуть» → «Новая версия» →
   скопировать URL в константу API_URL в app.js, если URL изменился.
3. После правок проверять контрольные поиски (Ctrl+F) из описания правки.

## Ограничения

- Сервер отдаёт последние 500 смен и 500 перевозок — аналитика за большие периоды неполна.
- Правка отрезков рассчитана на смены без уже выданного путевого листа: если ПЛ выписан,
  нумерация останется занятой, а лист будет собран по старым данным.
