Проект: Приложение для управления сменами курьеров

Описание:
Это веб-приложение предназначено для управления сменами курьеров, включая запись, отслеживание и отчетность. Оно включает в себя функционал для работы с путевыми листами, справочник врачей и клиник, а также систему авторизации и управления пользователями.

Основные функции:

Управление сменами курьеров
Запись и редактирование маршрутов
Управление путевыми листами
Справочник врачей и клиник
Система авторизации и управления пользователями
Отчеты по сменам
Технологии:

HTML5/CSS3
JavaScript
Node.js (для серверной части)
Google Apps Script (для развертывания)
Как использовать:

Откройте index.html в вашем браузере.
Зарегистрируйтесь или войдите в систему.
Используйте меню для доступа к различным функциям.
Примечание:
Для работы приложения необходимо подключение к интернету. В случае отсутствия сети некоторые функции могут быть недоступны.
