## Что нельзя забывать при каждом релизе

1. **Изменил index.html / app.js / sw.js → подними CACHE в sw.js.**
   Иначе телефоны водителей останутся на старой версии, а баг будет
   «непочиненным». Это уже дважды было причиной «фикс не работает».
   Проверка версии на телефоне: виден ли эффект нового релиза
   (например, точки в верхнем регистре в записи отрезка).
2. **Изменил api.gs → переразвёртывание веб-приложения** (Развернуть →
   карандаш → Новая версия). Если изменился URL — обнови API_URL в app.js
   и это тоже тянет за собой инкремент CACHE.
3. **Проверь офлайн-путь после правок очереди:** пакет должен падать в
   localStorage и уходить сам. Никогда не «терять» введённые данные —
   это главный страх водителей («я ввёл, а оно пропало»).

## Принятые решения (и почему)

### Маршрут смены
- **Старт маршрута — «Откуда» первого отрезка смены**, даже если отрезок
  «Офис → Офис». Раньше первый отрезок без перемещения пропускался,
  и маршрут начинался со второго отрезка → получалось «Ижевск, Бодья, Ижевск».
- **Крайние Ижевск (начало и конец маршрута) заменяются на Офис.**
  Смена по определению стартует и финиширует в Офисе.
- **Схлопывание соседних Офис/Ижевск** — считаются одной точкой.
- Логика взята 1:1 из упрощённой версии (compressRoute), плюс
  регистронезависимое сравнение (см. ниже).

### Регистр точек
- **Итог: точки хранятся как «Первая Заглавная»** — `Ижевск`, `Можга`, `Офис`.
  Так в справочниках, отрезках и маршрутах единый вид, читается лучше капса.
- **Все сравнения точек в коде — через toUpperCase().** Это страховка от
  старых записей «ОФИС»/«ИЖЕВСК» в таблице: они считаются той же точкой.
- **Урок:** раньше сравнение с литералом `'ИЖЕВСК'` не срабатывало,
  потому что после отказа от подмены в canonName точки стали «Ижевск».
  Одна буква — и замена крайних точек молча перестала работать.
  Правило: любые строковые сравнения доменных сущностей — без учёта регистра.

### Одометр и «всего»
- Водитель вводит **показание одометра в точке «Куда»**, а не километраж
  отрезка. «Всего» в сообщении — это просто последнее введённое показание,
  **без пересчётов** (по требованию водителей/старшего).
- Суммы по смене (totalKm, cityKm, highwayKm, odoEnd) считаются из отрезков
  в finishShift — на корректных данных совпадают с последним показанием.

### Разделение с листовой формой (упрощённой версией)
- Листовая форма и PWA не пересекаются по листам, **кроме Doctor**.
- Перевозки врачей PWA теперь пишутся на **DoctorS** (API.DOCTORS).
  Лист Doctor остаётся упрощённой версии.
- Старые записи PWA в Doctor переносить не нужно: сводки по врачам уже
  внутри смен (колонка «врач»), отдельно они нигде не читаются.
- Упрощённую версию при возможности отключить: предназначена для проверки в монопольном режиме.

### Офлайн и очередь
- Всё, что не ушло, живёт в localStorage-очереди; на дашборде — счётчик
  неотправленных записей.
- Пакет ретраится до 3 раз, потом пропускается с просьбой сообщить старшему —
  «ядовитый» пакет не должен блокировать очередь навсегда.
- Сервер отвечает «Сервер занят» вместо ожидания лока: клиент кладёт пакет
  обратно и повторяет позже.

### Смена и авто
- Авто нельзя сменить в открытой смене после первого отрезка: одометр начала
  привязан к конкретной машине.
- Авто офлайн-добавления (без row) отправляется как «driver», не «driveredit» —
  иначе сервер отклонит правку без номера строки и она потеряется.

## Известные особенности / долги

- Нормализация регистра точек в справочниках (Points/InterPoints/MedPoints):
  разовый скрипт normalizePointCase() из README — запустить, если ещё не.
- Заглушка `мой_адрес/exec` в API_URL app.js — перед выпуском заполнить.
- Часовой пояс: время берётся с телефона. Для Удмуртии не проблема;
  если появятся водители из других поясов — вернуться к вопросу.

## Чек-лист проверки смены (боевой тест)

- [ ] Открыть смену, ввести отрезки «ижевск→бодья» строчными → в записи «Ижевск → Бодья»
- [ ] Отрезок «офис→офис» не ломает маршрут: старт = Офис
- [ ] Закрыть смену → маршрут вида «Офис, ..., Офис» (крайние точки)
- [ ] «Всего» после отрезка = введённый одометр
- [ ] Перезапустить приложение в середине смены → сводка смены на месте
- [ ] Отключить сеть, записать данные → счётчик очереди на дашборде;
      включить сеть → всё уходит само
- [ ] Перевозка врача после деплоя → строка в DoctorS, Doctor чист
