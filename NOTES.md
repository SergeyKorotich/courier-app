# Note.md — заметки по проекту «Курьер — смены»

## Принятые решения

- **Одометр.** В смене вводится только показание одометра; пробег отрезка считается
  как разница с предыдущим. При правке отрезка меняется только сам отрезок
  (пункты и его пробег), одометр этого и всех последующих отрезков пересчитывается
  каскадом от одометра начала смены. Маршрут смены строится автоматически
  (compressRoute: схлопывание соседних ОФИС/Ижевск, края — в ОФИС).
- **Тариф.** Общий на всех, история записей «дата + тип (за км/за час) + сумма».
  Смена относится к тарифу по дате смены; итог месяца = сумма произведений
  по каждому тарифному периоду (складываются итоги периодов разных тарифов).
  Считается только при рендере дашборда, в таблицу смен не пишется.
- **Роли.** Кластер ролей — уникальные непустые значения колонки «роль» на Drivers.
  Первичный ввод новой роли сохраняет её в кластер для последующего выбора из списка.
- **Собственник авто.** При правке автомобиля в настройках реквизиты собственника
  подтягиваются с листа Cars (сервер отдаёт их вместе со списком машин).
- **ОФИС/Ижевск** — эквивалентные точки: схлопываются в маршруте, но не в отрезках.
- **Авто в смене** фиксируется после первого отрезка — одометр начала привязан к машине.

## Известные ограничения

- Смена без отрезков не существует: последний отрезок удалить нельзя, только смену целиком.
- Удаление смены не проверяет выданный ПЛ № — номер останется занятым.
- readShifts/readDoctorsAll отдают последние 500 записей — аналитика «за всё время» ограничена.
- Свободный текст в полях разрешён (canonName приводит к канону), подсказки — только префикс.

## В плане

- Аналитический дашборд «бигбос»: маршруты и перевозки за месяц/неделю/день,
  срезы по водителю, врачу и точке (серверная часть doctorsAll готова).
- Построение маршрута: точки посадки врачей + точка назначения, оптимизация порядка
  и времени; начальная точка — всегда офис. Нужен выбор между Яндекс Картами (ключ API,
  реальные расстояния и время) и упрощённым построителем.
